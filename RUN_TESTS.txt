🧠 ALGORITHM DETAILS
═══════════════════════════════════════════════════════════════════════════════

LINE-OF-SIGHT (LOS)
  Range Check:    Chebyshev distance ≤ 3
  Wall Detection: Bresenham's line algorithm
  Time:           O(9) checks per target

PATHFINDING (BFS)
  Time:           O(grid² ) = O(225)
  Space:          O(grid²) = O(225)
  Collision:      Excludes friendly bot positions
  Result:         Shortest collision-free path

COMBAT TARGETING
  Scan:           All enemy bots in LOS
  Filter:         Energy > 0
  Priority:       Min HP (wounded enemies first)
  Result:         Single target or no target

MULTI-BOT COORDINATION
  Reserved Set:   All friendly positions
  Conflict Check: O(num_bots)
  Result:         All bots have collision-free moves

🐛 DEBUGGING FAILED TESTS
═══════════════════════════════════════════════════════════════════════════════

If a test fails:

1. READ THE ERROR MESSAGE
   Bot outputs {"action": {"type": "wait"}, "error": "..."}?
   → Check error type (json_decode_error, state_parse_error, etc.)

2. CHECK INPUT FORMAT
   Valid JSON?  Run: echo '<input>' | python -m json.tool
   All fields?  Check: grid_size, walls, my_bots, enemy_bots, etc.

3. VIEW GRID VISUALIZATION
   Use interactive_tester.py → Press [2] to see grid
   Find walls, orbs, enemy positions

4. TRACE PATHFINDING
   Add debug: print("Path:", path)
   Check: Is path collision-free? Length correct?

5. VERIFY LOS
   Add debug: print("Can see:", self.has_line_of_sight(start, end))
   Check: Distance ≤ 3? No walls blocking?
